# Jarvis Knowledge

This directory may eventually index stable, evidence-cited facts needed by
Jarvis. Mission-scoped drafts, inferences, assumptions, conversations, and
authorization intents do not belong here. Only directly verified `FACT`
updates may be proposed, and material changes require explicit human review.

Mission 003A stores immutable evidence-backed candidates and trusted FACT or
INTENT entries. Promotion requires independent Emma PASS plus exact José
authorization. Conversations are not blindly stored and model weights are not
modified. Search, ranking, and reasoning are deferred.
